# HTML Email Development Portfolio

A collection of responsive HTML email templates demonstrating practical email development techniques, including table-based layouts, inline CSS, mobile optimization, and cross-client-conscious design.

## Live Portfolio

[View Live Portfolio](https://html-email-portfolio.vercel.app/)

## Email Showcase

The portfolio includes eight production-style email examples:

1. **SaaS Product Launch** — Marketing email for AutomateAI 2.0
2. **IT Security Alert** — Password update notification
3. **Subscription Welcome** — SaaS onboarding and subscription confirmation
4. **Account Verification** — Email verification and account activation
5. **Payment Confirmation** — Ecommerce transaction and order summary
6. **Tech Newsletter** — Editorial newsletter featuring AI, automation, and developer content
7. **Event Invitation** — AI Automation Summit registration email
8. **Support Ticket Update** — Customer support and ticket status notification

## Email Development Techniques

- Table-based email layouts
- Nested presentation tables
- Inline CSS
- Responsive email design
- Mobile-friendly layouts
- Email-safe typography
- Preheader text
- Table-based CTA buttons
- Structured transactional data
- Responsive content stacking
- Fallback links

## Compatibility Targets

Templates are designed with the following email clients in mind:

- Gmail
- Outlook
- Apple Mail
- Yahoo Mail

> These are compatibility targets and should not be interpreted as formal cross-client testing results.

## Built With

- HTML5
- CSS3
- Table-based HTML email layouts
- Inline email CSS

The portfolio website uses modern CSS, while the email samples intentionally use conservative email-development techniques for better email-client compatibility.
